# Personal homepage

React, TypeScript, and Vite. `/` is the hello introduction; `/play.html` loads the
original MacBook/sticker scene. `src/` owns components and data, `public/` owns
static resources, and `scripts/` maintains public GitHub profile data.

Run `npm ci`, `npm run dev`, `npm test`, or `npm run build` in this directory.
Production output is `dist/`.
