# Noto Serif SC introduction subset

Source: Google Fonts Noto Serif SC, https://github.com/google/fonts/tree/main/ofl/notoserifsc
License: SIL Open Font License, included in OFL.txt.
Weights: 400 and 600. Subsets contain only 我是独立开发者、学生.
Fetched via the Google Fonts text-subsetting endpoint. Extend the subset when
changing the Chinese introduction. Latin text uses Exposure / GT Super Text.

`work-regular.ttf` is a separate 400-weight subset for Work descriptions and
links, including the GitHub invitation, Contact introduction, and the scroll hint
`下滑探索更多`. It includes all Chinese characters and
punctuation in those strings so mobile and desktop do not mix local fallback
fonts. Extend this subset when changing Work copy. It uses the same source and
license above; Latin text remains GT Super Text.
